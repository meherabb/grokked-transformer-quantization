# Manifests

- `source_inventory.csv` maps supplied source artifacts to curated repository locations.
- `notebook_manifest.csv` documents executed notebook roles.
- `figure_manifest.csv` distinguishes main, supplementary, and archive-only figures.
- `table_manifest.csv` inventories notebook-generated result tables.
- `checksums_sha256.txt` contains SHA-256 hashes for packaged repository files (excluding the checksum file itself).
