# Source figure archive

These files preserve original notebook figure exports and superseded publication drafts for provenance.

Do **not** interpret every figure in this directory as current manuscript evidence. In particular, historical files such as `fig3_mechanism`, `fig6_train_fraction`, and `fig7_statistical_rigor` contain labels or inferential statements that were superseded by the final audit. The original `fig8_grokking_trajectory` is also superseded by the publication-facing final trajectory figure.

Use `../main/` and `../supplementary/` for the current publication-facing visual record.
