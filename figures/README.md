# Figures

This directory deliberately separates publication-facing figures from historical/source notebook exports.

## `main/`

Four publication-facing main-paper figures, each provided as PDF and PNG.

## `supplementary/`

Seven supplementary figures used by the audited supplement, each provided as PDF and PNG.

## `source_archive/`

Original and historical notebook figure exports retained for provenance. Some source figures contain superseded labels or interpretations and are **not** current publication evidence. See `source_archive/README.md` and `docs/FIGURE_PROVENANCE.md`.
