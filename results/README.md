# Results tables

`tables/csv/` and `tables/latex/` preserve the notebook-generated summary tables supplied with the research package.

These files are source outputs rather than a guarantee that every embedded historical hypothesis interpretation survived the later audit. For current claims, use the audited manuscript/supplement and `docs/AUDIT_NOTES.md`.

The underlying row-level numerical records are available under `data/processed/consolidated/` and in the original archives.
